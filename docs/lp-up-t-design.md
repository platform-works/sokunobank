# Up-T(オリジナルTシャツ)送客LP 設計書

作成日: 2026-10-11 / 状態: 設計案(未実装・未公開)

## 0. 前提・事実確認ルール

- Up-Tの納期・料金・最低枚数・対応アイテム・無料サポートの内容は**公式サイトで未確認**。本書の `【要確認】` は、公式で確認が取れるまで画面に出さない(CLAUDE.md「利用者に見える事実は一次情報のみ」)。
- 「最短◯日」「◯円〜」等の数値は、確認後に `Provider.formatOptions` 等へ持たせ、LP本文へは直書きしない。
- CTAは**Up-T 1社のみ**(メイン事業者 `isPrimary: true`、`lp.ctaProviderId`)。他社への導線は作らない。
- 新カテゴリー「オリジナルTシャツ(slug案: `original-tshirt`)」としてDM型スキーマ(`dm.json`と同じ)で追加し、`/lp/original-tshirt/` を広告LPとする。LPは `noindex` を維持(既存LPルートの仕様)。
- アフィリエイトタグ・PR表記・`rel="sponsored"` は既存ルールに従う。タグ未取得の間は `officialUrl` へ通常リンク。
- 個人名・実在しない導入事例・お客様の声は載せない(捏造禁止)。「事例的な見せ方」は**架空の利用シーンと明示したシミュレーション**に限る。

## 1. LPの設計コンセプト

**一言: 「Tシャツ制作の"間に合うか・頼めるか"を、30秒で整理してからUp-Tへ送る」**

| 軸 | 内容 |
|---|---|
| 役割分担 | Up-T=制作・発送の実行役 / 即納バンク=用途・条件・納期の**判断整理役** |
| 補完対象 | Up-T本体は個人・ファン向けの印象が強い → 学校・団体・法人の担当者向けに「用途整理・発注前チェック・分岐導線」を補う |
| 3不安への対応 | 「急ぎ」→納期逆算 / 「初めて」→発注前チェックリスト+手順 / 「デザインがない」→パターンB導線 |
| トンマナ | 既存デザイントークン(グリーン系・白基調)。オレンジ(`--color-urgent`)は「納期・即納」情報のみ。ポップな装飾・Tシャツ写真の多用は避ける |
| 誇大表現 | 「最安」「必ず間に合う」「No.1」は使わない。期日は「公式で確認」と併記 |
| CV | Up-Tへのクリック(主)。補助CVとして「条件サマリーのコピー/印刷」(発注担当者が社内稟議・見積依頼に使えるため) |

## 4. ファーストビュー案

**キャッチ(H1)**
> 急ぎのオリジナルTシャツ、まず「間に合うか」から整理しませんか。

**サブコピー**
> 学園祭・イベント・展示会・社内行事。デザインデータの有無で進め方を選べば、迷う時間を減らせます。条件を整理してから、Up-Tで制作を進められます。

**バッジ(小)**: 学校・サークル・企業の発注担当者向け / 条件整理は1分 / PR(広告)

**分岐UI(FV直下、2カード・タップで該当セクションへ)**

- **[A] デザインデータがある**
  ロゴ・イラスト・入稿データがすでにある。最短で進めたい。
  → 「納期と条件を確認する」
- **[B] デザインがまだ決まっていない**
  ラフ案だけ/誰に頼めばいいか分からない。相談しながら進めたい。
  → 「進め方と無料サポートを確認する」

**FV補助テキスト**: 「どちらか分からない場合は、先に下の“納期の目安チェック”へ」

**CTA**: FV内はUp-Tへの直接CTAを置かず、分岐カードをCTAとして機能させる(判断を挟むことでクリックの質を上げる)。ただし画面下部固定バー(スマホ)に常時「Up-Tで作成する」を置く。

## 5. 「デザインあり/なし」分岐導線設計

```
FV [A あり] ──→ #route-a「データ入稿で進める」
                  ├ 入稿前チェック(形式・解像度・印刷位置)【入稿仕様は要確認】
                  ├ 納期チェック(自動でA設定)
                  └ CTA-A「デザインを持っているので今すぐ作成する」

FV [B なし] ──→ #route-b「相談しながら進める」
                  ├ 進め方3パターン(自分で作る/テンプレート/デザイナー依頼)【内容・費用は要確認】
                  ├ ラフ案でも大丈夫なケースの整理
                  └ CTA-B「相談しながら作りたいので無料サポートを見る」

どちらも: 大口(目安100枚〜※閾値は要確認)→ #bulk「大口・法人・学校の方へ」→ CTA-C
```

分岐の再合流: 各ルート末尾に「やっぱりもう一方を見る」リンクを置き、誤選択による離脱を防ぐ。
URLパラメータ `?route=a|b`(GA4計測と共有リンクのため)。ページ内は単一HTML・JS最小(`<details>`+軽量JS)。

## 6. 納期目安の選択式UI案

**方針**: 実際の納期は**Up-T公式の締切・工程に依存し即納バンクは断定できない**。ツールは「条件の整理+公式で確認すべき項目の提示」を行い、日付計算は公式の数値が確認できるまで**逆算チェックリスト形式**にとどめる。数値確認後に日付計算を有効化できる設計にする。

**選択項目(各項目ラジオ/チップ、44px以上)**

| # | 質問 | 選択肢 |
|---|---|---|
| 1 | デザインデータは? | ある / ラフのみ / ない |
| 2 | 利用用途は? | 学校・学園祭 / サークル / 企業 / イベント・展示会 |
| 3 | 希望枚数は? | 〜9 / 10〜29 / 30〜99 / 100〜299 / 300〜 |
| 4 | 使いたい日(希望納期)は? | 日付入力 or 「1週間以内/2週間以内/1か月以内/未定」 |
| 5 | 印刷内容は? | 片面 / 両面 / フルカラー / 分からない |
| 6 | 進め方は? | 自分で作る / 相談して作る / 分からない |

**出力(結果カード)**

1. **あなたの条件サマリー**(コピー・印刷可能。稟議・チーム共有用)
2. **おすすめルート**: ルールベースで1つ表示

| 条件 | 表示 |
|---|---|
| 1=ある & 6=自分で | 「最短ルート」→CTA-A |
| 1=ない or 6=相談 | 「相談ルート」→CTA-B |
| 4が「1週間以内」or「2週間以内」 | 納期注意バナー(オレンジ):「入稿〜到着までの日数は公式で確認を。使用日から逆算して早めの入稿を」 |
| 3が100枚以上 | 「大口・法人向け窓口を確認」→CTA-C |
| 2=学校/企業 | 「請求書払い・見積書など支払い方法」を確認項目に追加【対応可否は要確認】 |

3. **Up-Tで確認すべき項目リスト**(動的): 納期(入稿締切)/ 配送先・日時指定 / 支払い方法 / 追加料金の有無
4. 結果カード直下にCTA。

**注意書き(必須)**: 「納期・料金は変動します。最新の条件はUp-T公式でご確認ください。本ツールは条件整理のための目安です。」

## 9. FAQ案(回答は公式確認後に確定)

1. **デザインデータがなくても作れますか?** — 進め方は「自分で作る/相談して作る」等から選べます【公式の方法・費用は要確認】。まず「進め方を選ぶ」で整理を。
2. **急ぎでも対応できますか?** — 納期は枚数・内容・時期で変わるため、使用日から逆算して公式で入稿締切を確認してください【最短日数は要確認】。
3. **少部数でも大口でも頼めますか?** — 最低枚数・大口時の相談可否は公式でご確認ください【要確認】。目安チェックで枚数帯別の確認項目を提示します。
4. **学校や法人でも使えますか?** — 請求書払い・見積書等の対応は公式でご確認ください【要確認】。条件サマリーを社内共有に使えます。
5. **サイズはどう決めればいいですか?** — 事前に全員のサイズを集計→予備枚数の検討を(サイズ表は公式で確認)。
6. **データの形式・解像度は?** — 入稿仕様は公式でご確認ください【要確認】。
7. **途中でデザインを変更できますか?** — 修正可能な範囲・期限は公式でご確認ください【要確認】。
8. **追加注文はできますか?** — 同デザインの再注文の可否・手順は公式でご確認ください【要確認】。
9. **即納バンクとUp-Tの関係は?** — 即納バンクは条件整理を行う比較・案内サイトで、制作・発送はUp-Tが行います。広告掲載による収益があります(PR)。

※ FAQPage構造化データは `FaqSection.astro` が自動出力。

## 11. SEO・タイトル/ディスクリプション案

LPは広告用のため `noindex`(既存仕様を維持)。広告のランディング/ブランド向け、および将来indexする場合の案:

- **title案1(32字内)**: オリジナルTシャツを急ぎで作る|納期と進め方を整理【即納バンク】
- **title案2**: 学園祭・サークル・企業のTシャツ制作|納期の目安と発注前チェック
- **description案**: 急ぎのオリジナルTシャツ制作を、デザインの有無・枚数・使用日から整理。学園祭・サークル・企業イベントの発注前チェックリストと、納期の目安チェックを用意。制作はUp-T公式へ(PR)。
- **H1**: 4章のキャッチ。

**SEO安全ゲート(CLAUDE.md準拠)**
- 新規index可能URLは**0**(LPはnoindex、sitemap非掲載)。
- 将来、ガイド記事化する場合(例:「クラスTシャツの納期逆算」「学園祭Tシャツ発注の手順」)は、既存ページとの意図重複を確認し、2ページ以上へ内部リンクできる場合のみ作成する。用途×地域等の量産ページは作らない。
- `llms.txt` 追記は、カテゴリーを `published` にする時点で実施。

## 2. モジュール構成

| モジュール | 役割 |
|---|---|
| `sourceLicenseValidator` | 取得元×操作(集計取得/集計公開/本文取得・解析・保存・公開/画像)の許諾レジストリ、公開可否判定 |
| `productIdentityMatcher` | JAN一致>型番+ブランド一致で同一商品を束ねる。容量等が違えば別商品。名前だけの類似は低信頼(0.3)で対象外 |
| `reviewDataConnector` | 集計値と(許諾済み経路があれば)本文を取得。無ければ「欠測」を記録し補完生成しない |
| `reviewSentimentAnalyzer` | 許諾済み本文のみ、テーマ別の肯定/否定件数・用途・期間を集計。重複と販売店のみのレビューを除外 |
| `reviewTrustEvaluator` | 件数<10=不足、<30=参考情報。評価分布の偏り・古さ・重複を異常傾向として記録(不正の断定はしない) |
| `rankingEngine` | 重み 評価30/用途30/仕様20/価格15/納期5(初期仮説)。評価不能の軸は再配分、重み合計0.5未満は対象外、3件未満は順位を付けず候補一覧 |
| `lpContentGenerator` | LP構造を生成。Amazon CTAは確認済みリンクのみ、画像は楽天/Yahoo!のみで出典+リンク併設 |
| `pipeline` | 上記をつなぐDRY_RUNオーケストレーター。実行ログ(RunLogEntry)を出力 |

## 3. 守っている制約
- 報酬率・提携有無は入力型(`RankingCandidate`)に存在しない。順位に混ぜられない
- Amazon出品は `RANKING_SOURCES`(yahoo/rakuten)外。順位計算・価格表・画像に使わない。他社データでAmazonの価格・画像を代用しない
- アソシエイトリンクは `tag=sokunobank-22`・`www.amazon.co.jp`・ASIN形式を検証し、未登録ならCTA非表示。ASIN推測生成なし
- 画像・集計評価の公開許諾が `unverified` の間は `publish.publishable=false`(公開保留)
- 「購入者全体の評価」とは書かない(`mayClaimOverallBuyerRating` は常にfalse)

## 5. 利用規約の確認結果(2026-10-24)

**注意**: 楽天の規約は英訳(参考用、法的効力は日本語原文)から読んだ。公開前に日本語原文と、規約から参照される「クレジット表記」「ガイドライン」ページを必ず確認すること。

### 楽天ウェブサービス
- **リンク先の制限(最重要)**: 第8条は、ウェブサービスを使っている部分から**楽天サイト以外へのリンクを張ってはならない**旨を定める。→ 楽天の商品データ(画像・価格・評価)を載せたブロックの中に、Amazonのリンクや他社アフィリエイトのリンクを混在させない。Amazon CTAは楽天データのブロックから分離した別領域に置き、設計上も同一カードに同居させない(日本語原文で要確認)
- **アフィリエイト**: 第3条・第10条(4)(5)は、報酬目的の利用は楽天アフィリエイト経由に限り、楽天の商品に他社アフィリエイトを使うことを禁止。楽天商品へのリンクは `affiliateUrl`(楽天アフィリエイトID指定時)を使う
- **保存・共有**: 第10条(7)(9)は、定められた目的以外の複製・改変、不特定多数が見られる場所への保存を禁止。DB・JSONへの恒久保存や、取得データをそのままリポジトリに置くことはしない。保存可能期間の記載は読み取れず**未確認**
- **クレジット表記**: 第13条は、会社が求めた場合に提供元表示の義務。具体的文言は**未確認**(クレジット表記ページを要確認)
- **画像・レビュー**: 画像の表示条件、レビューの扱いは規約本文に記載を確認できず**未確認**。`publishImage` / `publishAggregate` は unverified のまま
- 禁止: 楽天商標に類似するURL、楽天との協力関係を示す表示、リバースエンジニアリング

### Yahoo!デベロッパーネットワーク
- **クレジット表示が必須**: 「Webサービス by Yahoo! JAPAN」を規定のHTMLソースのまま(改変・色変更・極端な縮小は禁止)、**ページ下部**に表示し、https://developer.yahoo.co.jp/sitemap/ へリンクする。最も目立つ要素にしない、提携を示唆しない
- **現状の不足**: `src/` 内に該当クレジット表示は見つからなかった(2026-10-24時点)。Yahoo! APIを使うcommerceページ全体に関わるため、**Footerへの追加をユーザー確認のうえ別途実施すること**
- データ保存・画像・アフィリエイト併記は、ガイドラインページに記載なし。LINEヤフー共通利用規約(ソフトウェアに関する規則)側のため**未確認**

### Amazonアソシエイトとの併用
- 運営規約の本文は取得できず、**他社アフィリエイトとの併用可否、価格表示条件は未確認**(二次情報のみ)
- 確認できている範囲の運用方針: Amazonの価格・画像・評価は表示せず、他社データで代用しない。CTAは楽天データのブロックと分離し、PR表記を付ける
- 有料広告として配信したAmazonリンクは対象外になる旨の改定報道あり(二次情報)

### 結論(実装上の取り扱い)
- 楽天: 取得のDRY_RUNまでは可。**LPへの画像・価格・評価の表示は、日本語原文の規約・クレジット表記・リンク制限の確認が済むまで保留**(`publishable=false` を維持)
- Yahoo!: 既存の表示は継続。クレジット表示の追加が必要
